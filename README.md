# ArvindSt
We present ArvindSt, an R package that implements a complete ecosystem for fitting, diagnosing, forecasting, and comparing five Arvind-based regression models:(RW1-approx), (tvLM), (SIMEX),Mixed Effects Regression, and Regime-Switching (HMM). It provides darvind, parvind, qarvind, rarvind, model-fitting, forecasting, k-fold and cross-validation.
